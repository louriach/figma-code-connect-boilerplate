Connect your Figma components to your codebase
This plugin scans your Figma file and exports a list of components that your development team can use to link Figma directly to your real code, so developers see live code snippets when inspecting components in Dev Mode.
1
Pick your pages
Choose which pages contain the components you want to connect, then click Scan.
2
Select components
Review the components found and check the ones you want to include in the export.
3
Export
Download figma-components.json and hand it to the Claude skill to finish setup.
You'll need a Figma Organisation or Enterprise plan for Dev Mode to display code snippets.
