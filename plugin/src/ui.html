Connect your Figma components to your codebase
This plugin scans your Figma file and exports a list of components that your development team can use to link Figma directly to your real code - so developers see live code snippets instead of auto-generated placeholders when inspecting components in Dev Mode.
1
Pick your pages
Choose which pages in this file contain the components you want to connect.
2
Select components
Review every main component found and check the ones you want to include.
3
Export
Download a figma-components.json file and hand it to your Claude skill to finish the setup.
You'll need a Figma Organisation or Enterprise plan for Dev Mode to display code snippets.
